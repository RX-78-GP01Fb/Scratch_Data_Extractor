# Scratch Data Extractor 🚀

Scratchの公開スタジオから「プロジェクト、コメント、メンバー、活動履歴」データを高速かつ安全に取得・可視化し、多様なフォーマット（JSON / CSV / TXT）でダウンロードできる完全クライアントサイド動作のデータ抽出ツールです。

## 🌟 特徴
- **超高速フェッチ**：`Promise.all` を用いた複数ページの並列データ取得。
- **データ抜け漏れ防止**：活動履歴には `dateLimit`（日時指定）による高精度なページネーションを搭載。
- **安全なローカル処理**：取得したデータはサーバーに一切保存せず、ブラウザ内（ローカル）でのみ処理・完結します。
- **多彩な出力形式**：JSON、全統合CSV、カテゴリー別CSV、メンバーTXTのエクスポートに対応。

## 🛠️ クイックスタート
1. リポジトリ内の `index.html` と `script.js` を同じフォルダに配置します。
2. ブラウザで `index.html` を開きます。
3. 抽出したいScratchのスタジオURL、またはスタジオIDを入力します。
4. 取得したい項目にチェックを入れて「抽出実行」ボタンを押します。
